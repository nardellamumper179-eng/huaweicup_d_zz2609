## 数据解释

- 图12的巡航海拔按求解程序的球面距离、5 m航线采样和DEM最近栅格规则重建，取沿线最高高程加50 m与悬停海拔的较大值。重建去程时间与最终JSON核对，允许误差小于0.05 s。去返程几何路径重合，双向箭头区分方向；标注引线不是运输航线。
- 图12采用三维高程示意，垂直比例经调整；航迹与节点突出显示。网关G01位置为O01海拔以上20 m。无中继任务的服务区使用灰色点。
- 图13底部粗线是区域缺口的最早至最晚时间范围，并不表示整个区间每一秒都有运输任务需要中继。
- 图14的分母是各区域基准直连缺口样本数，不是整段连续任务时间。只改变中继链路损耗，不改变直连缺口、航线、位置与时序。连线仅用于引导阅读离散情景。
- 图16、17按任务归属着色，不虚构行政边界或连续地域划分。两图范围、比例尺、地形色标一致。
- 图18各柱使用各自口径下的最优分区。两组固定分区内重派可将缺口由8降至6；重新选择分区后为4。不能将8到4的全部下降解释为同一分区内的重派效果。
- 图19的25%是附加比较条件，不是原题硬约束。三组10%情景无合法分区，因此曲线从20%起；未把不可行值当作零。曲线连接已计算情景，不断言阈值间的连续变化。
- 说明文件中第三问最低中继返航SOC有旧值；本套图表统一使用最终JSON中的57.36196%，显示为57.36%。
